# 基层社区网格化综合治理信息平台的设计与实现

本项目面向毕业设计，围绕“网格—居民—任务—事件”主线，建设一个可演示、可答辩、业务闭环清晰的社区治理信息平台。

## 当前阶段

当前已经从工程骨架进入核心业务闭环阶段。后端已实现会话认证、CSRF、权限与数据范围，以及用户、社区/网格、家庭户、居民的新增、详情、编辑和状态动作；四类核心角色使用固定编码维护，`/api/auth/navigation` 仅返回当前账号启用且获授权的动态菜单。前端按服务端列表渲染导航，以本地注册路由作白名单：成功空导航进入 `/forbidden`，只有请求失败才回退到权限过滤后的静态首项，权限变化会让相关旧会话立即失效。社区与网格均支持多人责任分配且必须有一名主负责人。居民身份证号和手机号支持授权精确检索与填写用途后的临时明文查看，查询、查看和审计查询均不返回敏感输入、密文或哈希；受限审计严格按历史 `scope_grid_id` 隔离，V6 的空范围历史不依据居民当前网格回填。事件类别可由系统管理员动态维护并受乐观锁和非终结事件引用保护；事件与任务均支持附件上传、列表、下载和受约束的软删除，前端为每个文件携带稳定 UUID `requestToken`，失败重试不会重复写入，任务提交复核只接受本任务附件。软删事务提交后清理物理文件，失败或进程中断留下的待清理记录由定时扫描幂等重试。治理概览除基础计数外，还返回按网格统计、类别占比和最近事件，且全程遵循数据范围。注册采用双轨审核：工作人员申请由管理员分配内部角色，居民注册通过不可逆身份指纹匹配既有居民档案，审核后只进入本人服务台。前端业务模块已接入对应表单、权限可见性、提交状态和错误反馈。

前端基线为 Node 22 + Vue 2.7.16，Element UI 采用组件级按需加载。数据库迁移由 `V1__baseline.sql` 至 `V9__grid_worker_navigation_scope.sql` 组成，共 17 张业务表。验证入口按“四类角色多账号 API 闭环”运行：隔离流水线会从零迁移、构建前后端、执行服务层测试与真实 MySQL 冒烟，并在真实浏览器中覆盖动态导航、治理概览、事件/任务附件和居民服务台；完成后自动清理本轮数据库、临时数据库用户、附件目录与进程。论文演示数据和 8 张桌面/移动端图片也已固化为可重复生成的隔离流程。

## 技术基线

- 后端：Java 17、Spring Boot 4.1.0、MyBatis Spring Boot Starter 4.0.0、Maven
- 数据库：MySQL 8.x、Flyway 版本化迁移
- 安全：Spring Security、BCrypt、服务端角色鉴权
- 前端：Node 22、Vue 2.7.16、Element UI 2.15.14（按需加载）、Vue Router 3、Vuex 3、Axios

## 核心模块

1. 用户、角色和菜单权限
2. 社区与网格区域管理
3. 居民及家庭户档案
4. 社区工作人员与网格员责任区分配
5. 网格任务派发与处理
6. 矛盾纠纷等治理事件上报
7. 事件受理、派发、处置、复核和办结
8. 事件与任务附件上传、列表、授权下载、软删除，以及事件与任务流转记录
9. 动态事件类别、治理统计大屏、网格按期办结率、类别占比和最近事件
10. 工作人员申请注册、居民身份注册与审核
11. 居民本人档案、本人事项上报与进度查询
12. 居民敏感字段精确检索、60 秒临时查看、访问审计与数据范围内分页查询

## 关键设计决策

- 复用东软颐养中心项目的角色菜单、CRUD、人员分配和审批思路，不复制养老业务表名与耦合代码。
- 事件和任务采用显式状态机，所有状态变化写入不可覆盖的流转记录。
- 派发、处置、复核等多表更新必须在后端事务中完成。
- 密码只保存 BCrypt 哈希；居民身份证号、手机号按“密文 + 哈希 + 后四位”设计。
- 居民敏感字段使用 AES-256-GCM；写入前必须通过环境变量提供随机 32 字节 Base64 密钥。
- 附件保存到配置化文件或对象存储目录，数据库只保存元数据；删除采用可审计软删除，任务附件与任务建立正式归属。
- 核心业务记录不做物理删除，使用状态字段归档。
- `V1__baseline.sql` 是首版结构基线，V2 补充用户角色软失效生命周期，V3 增加注册审核与居民角色，V4 清理居民注册申请遗留的明文手机号，V5 增加角色、菜单乐观锁和用户会话安全版本，V6 增加居民敏感字段访问审计，V7 增加任务附件、附件软删除与上传令牌幂等、类别版本、动态导航权限和审计范围网格，V8 增加强制改密状态，V9 将网格员导航入口与底层范围只读权限分离；已发布迁移禁止回改，后续继续新增版本。

## 明确不纳入首版

- 高精度 GIS 空间分析
- 原生移动端 App
- 多租户和跨区县数据交换
- AI 自动研判
- 复杂工作流引擎

这些能力不影响毕业设计的核心闭环，首版完成后再按答辩需要选择性扩展。
